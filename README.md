# HASAD Events — сайт-лендинг

Статичный сайт (HTML + CSS + JS, без сборки и без сервера). Креативное ивент-агентство HASAD Events, Душанбе. Визуальная концепция — **Chrome & Bubblegum**: оригинальный хромированный логотип HASAD, глянцевые розовые 3D-формы, реальные фото мероприятий.

## Структура

```
index.html                 — вся страница
404.html                   — страница «не найдено» для хостинга
assets/css/styles.css      — стили, цвета, адаптив
assets/js/main.js          — интерактив: меню, вкладки услуг, галереи проектов, форма → WhatsApp
assets/fonts/              — шрифты Unbounded и Manrope (кириллица + латиница, свои копии, OFL)
assets/js/bubbles.js       — живые 3D-капли «жвачка + хром» (three.js) на первом экране и в контактах
assets/vendor/             — three.js (локальная копия, MIT)
assets/img/brand/          — логотип: хромированный, розовый, отдельные буквы для анимации, иконки
assets/img/photos/         — фото мероприятий, по 2 размера: *-sm.webp (820px) и *-lg.webp (1600px)
assets/img/3d/             — отрендеренные 3D-объекты (хром, розовая жвачка, кольцо)
assets/img/og-image.jpg    — превью ссылки для соцсетей и мессенджеров
```

## Разделы

1. Первый экран — анимированный хромированный логотип HASAD поверх фото с вечеринки в Tanin (`hero-tanin-*.webp`, медленный «дышащий» зум), слоган, кнопка «Обсудить мероприятие», 3D-капли
2. Позиционирование (одна фраза) · О нас · Услуги (6 направлений, вкладки) · Форматы (5) · Проекты (фильтр + галерея каждого проекта, ссылка вида `#project-gatsby`) · Площадки и опыт · Подход · Продвижение и аудитория · Работа с бюджетом · Этапы работы · Контакты и география

## Форма заявки

Сервера нет: при отправке форма собирает имя, телефон, тип мероприятия, бюджет и комментарий в одно сообщение и открывает WhatsApp на номер **+992 98 088 94 31** — клиенту остаётся нажать «Отправить».
Номер задаётся в `assets/js/main.js` (`wa.me/992980889431`) и в ссылках в `index.html`.

## Запуск на своём домене

**Быстрый способ:** сборка с уже прописанным адресом сайта (canonical, превью для соцсетей, sitemap.xml, robots.txt, 404, `.nojekyll`; исходники не меняются):

```
python3 tools/build_site.py --url https://intervallclub-byte.github.io/hasad-events/ --out ../dist   # GitHub Pages
python3 tools/build_site.py --url https://ваш-домен/ --out ../dist --cname                          # свой домен на GitHub Pages
```
Содержимое `dist` загружается на хостинг как есть. Пункт 4 ниже при этом делать не нужно.

Сайт не зависит от временной ссылки и от сервиса, где он показан сейчас: все пути относительные, шрифты, 3D-библиотека и картинки лежат внутри папки, сервер и база данных не нужны. Подойдёт любой статический хостинг.

1. **Хостинг.** Загрузите содержимое папки `hasad-site/` (не саму папку, а то, что внутри) в корень сайта:
   - Netlify — перетащить папку на app.netlify.com/drop;
   - Vercel — `vercel deploy` из папки;
   - GitHub Pages — включить Pages для ветки/папки;
   - обычный хостинг с панелью (cPanel, ISPmanager и т. п.) — загрузить файлы в `public_html` / `www`.
2. **Домен.** В настройках хостинга добавьте свой домен. У регистратора домена пропишите DNS-записи, которые даст хостинг (обычно `A`-запись для `ваш-домен.tj` и `CNAME` для `www`).
3. **HTTPS.** Включите бесплатный сертификат (Let's Encrypt) и перенаправление `http → https` и `www → без www` (или наоборот) — в Netlify/Vercel/GitHub Pages это галочки в настройках.
4. **Адреса для превью в соцсетях.** В `index.html` в начале `<head>` есть комментарий «ЗАПУСК НА СВОЁМ ДОМЕНЕ»: замените `example.com` на ваш домен, раскомментируйте `canonical` и `og:url`, а в `og:image` и в JSON-LD (`"image"`, `"logo"`) укажите полный адрес вида `https://ваш-домен/assets/img/og-image.jpg`. Без этого Instagram/WhatsApp/Telegram могут не показать картинку-превью ссылки.
5. **Карта сайта (по желанию).** Создайте `sitemap.xml` с одним адресом `https://ваш-домен/` и добавьте в `robots.txt` строку `Sitemap: https://ваш-домен/sitemap.xml`. Затем добавьте сайт в Google Search Console и Яндекс Вебмастер.
6. **Страница 404.** `404.html` уже есть; Netlify и GitHub Pages подхватят её сами, на обычном хостинге укажите её в настройках ошибок (или в `.htaccess`: `ErrorDocument 404 /404.html`). Она рассчитана на размещение сайта в корне домена.
7. **Проверка после запуска.** Откройте сайт с телефона: шапка, меню, вкладки услуг, галереи проектов, форма (должна открыть WhatsApp с текстом заявки). Проверьте превью ссылки через developers.facebook.com/tools/debug или отправив ссылку себе в Telegram.

Перенаправления и настройка маршрутов не нужны: это одна страница, разделы открываются по якорям (`#about`, `#projects`, `#project-gatsby` и т. д.).

## Как заменить или добавить фото

1. Подготовьте изображение и сохраните две версии в `assets/img/photos/`: `имя-sm.webp` (длинная сторона ~820px) и `имя-lg.webp` (~1600px).
2. Для галереи проекта добавьте строку `['имя', 'описание фото']` в объект `PROJECTS` в `assets/js/main.js`.
3. Фон первого экрана — файлы `hero-tanin-2560.webp` и `hero-tanin-1280.webp` (блок `.hero__reel` в `index.html`). Чтобы поставить другое фото, сохраните его в тех же двух размерах под этими именами или поменяйте пути. Слайд-шоу из нескольких фото тоже поддерживается: уберите класс `hero__reel--still` и добавьте ещё `<img data-src="...-lg.webp" alt="">` — они начнут сменять друг друга.

## Видео

Когда появятся ролики мероприятий: сожмите в MP4 (H.264, 720–1080p, 10–20 сек, без звука, до ~4 МБ) и замените блок `.hero__reel` на
`<video autoplay muted loop playsinline poster="assets/img/photos/90s-dream-wide-lg.webp"><source src="assets/video/reel.mp4" type="video/mp4"></video>` — стили для фона уже подходят (тот же `object-fit: cover`).

## Локальный просмотр

```
cd hasad-site
python3 -m http.server 8000
# открыть http://localhost:8000
```
Если просто открыть `index.html` двойным щелчком, сайт работает (меню, вкладки, галереи, форма), но без 3D-капель: браузеры не загружают 3D-модуль из локального файла. На хостинге всё работает полностью.
